// sous le capot

  • Tirage pondéré sans remise : chaque rareté a un poids, et une carte obtenue sort du tirage. Pas de doublon possible.
  • Rouleaux : bandes de symboles générées à chaque tirage, animées en CSS avec une courbe qui dépasse légèrement pour l'effet de rebond. Les cartes Or font durer le 3e rouleau.
  • Levier : glisser avec les Pointer Events, retour en ressort (ease-out-back) calculé à la main.
  • Sauvegarde de la collection dans le navigateur (localStorage).
  • Toutes les cartes sont décrites dans un seul fichier de données, comme des ScriptableObjects.
